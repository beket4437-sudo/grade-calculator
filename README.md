# Grade Calculator

A console-based C++ application designed to calculate student average scores and assign final letter grades.

## Features
- Accepts multiple student records until the user enters `end`.
- Reads five test scores per student with input validation (0–100 range).
- Calculates the average score to one decimal place and assigns a letter grade (A, B, C, or F).
- Displays the total student count and overall class average upon completion.

## How to Run
1. Copy the code from `main.cpp` into an online compiler such as [OnlineGDB](https://www.onlinegdb.com/) (select **C++**) or compile locally using `g++ main.cpp -o grade_calculator`.
2. Run the program and follow the on-screen prompts.
